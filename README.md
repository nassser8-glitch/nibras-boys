# نبراس — الإصدار 0.1

نظام إدارة مدرسي — هذه بداية النظام الكامل الموصوف في وثيقة البنية التقنية.
تشمل هذه النسخة: تسجيل الدخول، إدارة المستخدمين، إدارة الطلاب، إدارة الفصول.

الوحدات القادمة (0.2 وما بعدها): الحضور، الملاحظات/السلوك، التحويلات، لوحة
المدير، التقارير، الإشعارات.

## المتطلبات

- Node.js 18 أو أحدث
- قاعدة بيانات PostgreSQL (محليًا أو عبر خدمة مثل Supabase / Neon / Railway)

## خطوات التشغيل

1. تثبيت الحزم:

   ```bash
   npm install
   ```

2. نسخ ملف متغيرات البيئة وتعديله:

   ```bash
   cp .env.example .env
   ```

   عدّل `DATABASE_URL` ليشير إلى قاعدة بياناتك، وضع قيمة عشوائية لـ
   `NEXTAUTH_SECRET` (يمكن توليدها بالأمر `openssl rand -base64 32`).

3. إنشاء الجداول في قاعدة البيانات:

   ```bash
   npx prisma db push
   ```

4. تعبئة بيانات أولية (مستخدم مدير + صف تجريبي):

   ```bash
   npm run db:seed
   ```

   بيانات الدخول الافتراضية:
   - البريد: `admin@nibras.local`
   - كلمة المرور: `Admin@12345`

   **مهم:** غيّر كلمة المرور فورًا بعد أول تسجيل دخول (سيُضاف لاحقًا خيار
   تغيير كلمة المرور من الواجهة).

5. تشغيل المشروع:

   ```bash
   npm run dev
   ```

   ثم افتح `http://localhost:3000`.

## هيكل المشروع

```
src/
  app/
    login/              صفحة تسجيل الدخول
    (dashboard)/        الصفحات المحمية (تتطلب تسجيل دخول)
      page.tsx           لوحة التحكم الرئيسية
      students/          إدارة الطلاب
      classes/           إدارة الفصول
      users/             إدارة المستخدمين
    api/                 نقاط نهاية API
  components/            مكونات مشتركة (الشريط الجانبي، مزود الجلسة)
  lib/                    إعدادات Prisma و NextAuth
prisma/
  schema.prisma           مخطط قاعدة البيانات
  seed.ts                  بيانات أولية
```

## الأدوار المتاحة حاليًا

- `ADMIN` — مدير: صلاحية كاملة
- `AGENT` — وكيل: إضافة/تعديل الطلاب
- `COUNSELOR` — موجه طلابي
- `TEACHER` — معلم
